# Calculadora básica en Python

## Descripción
Este programa solicita al usuario dos números y realiza las cuatro operaciones matemáticas básicas: suma, resta, multiplicación y división. Muestra los resultados en pantalla.

## ¿Cómo usarlo?
1. Ejecuta el archivo `calculadora_basica.py` en cualquier entorno de Python.
2. Ingresa el primer número cuando se te pida.
3. Ingresa el segundo número.
4. El programa mostrará inmediatamente los resultados de las operaciones.

## Ejemplo de ejecución

Ingresa el primer número: 10

Ingresa el segundo número: 2

--- Resultados ---

Suma: 10.0 + 2.0 = 12.0

Resta: 10.0 - 2.0 = 8.0

Multiplicación: 10.0 * 2.0 = 20.0

División: 10.0 / 2.0 = 5.0


## Resultado que obtienes

El programa te devuelve los valores de suma, resta, multiplicación y división de los dos números que ingresaste. Si intentas dividir entre cero, te advertirá que no es posible.
